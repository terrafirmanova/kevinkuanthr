# Studio Intelligence Prototype

Single-page interactive specification for an Etsy-adjacent art commerce and business intelligence platform.

## Run locally

Open `index.html` in a browser.

## Included modules

1. Public Gallery View with theme filters and popularity sorting
2. Pricing + Edition control engine with configurable multipliers
3. Production and framing supplier matrix
4. Theme radar analytics + six strategic management levers
5. Curatorial paragraph builder with live word counts
